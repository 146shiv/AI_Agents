# Product Requirement Document (PRD)

## Product Name

**AI Resume Analyzer + Interview Prep System**

## Objective

Build a SaaS platform where users upload resumes and receive:

- Resume score (ATS-based, 0–100)
- Improvement suggestions
- Job Description (JD) matching score
- AI-generated interview questions
- Mock interview (chat + voice)
- Weakness detection + improvement roadmap

## Target Users

| Segment | Description |
|---------|-------------|
| Students | College students preparing for campus placements |
| Job Seekers | Active job hunters optimizing their applications |
| Career Switchers | Professionals transitioning to new roles/industries |

## Success Metrics

| Metric | Target |
|--------|--------|
| Resume score improvement | Users see +15 avg score increase after applying suggestions |
| Interview success rate | 60%+ users report better interview confidence |
| User retention (30-day) | 40%+ monthly active users |
| System uptime | 99.5%+ |

## Release Phases

| Phase | Features | Priority |
|-------|----------|----------|
| Phase 1 | Auth + Resume Upload + Parsing | P0 (Must Have) |
| Phase 2 | Resume Scoring + Analysis + Suggestions | P0 (Must Have) |
| Phase 3 | JD Matching System | P0 (Must Have) |
| Phase 4 | Interview Question Generator + Mock Interview | P1 (Should Have) |
| Phase 5 | Voice Interview + Advanced AI Coaching | P2 (Nice to Have) |
