# User Stories

## Epic: Authentication

| ID | Story | Priority |
|----|-------|----------|
| US-AUTH-1 | As a new user, I want to register with my email so I can create an account | P0 |
| US-AUTH-2 | As a returning user, I want to log in with my credentials so I can access my data | P0 |
| US-AUTH-3 | As a logged-in user, I want to view my profile so I can see my account info | P1 |
| US-AUTH-4 | As a logged-in user, I want my session to persist so I don't re-login every page | P0 |

## Epic: Resume Management

| ID | Story | Priority |
|----|-------|----------|
| US-RES-1 | As a user, I want to upload a PDF/DOCX resume so the system can analyze it | P0 |
| US-RES-2 | As a user, I want to see all my uploaded resumes in a list | P0 |
| US-RES-3 | As a user, I want to see my resume's parsed content (skills, experience, etc.) | P0 |
| US-RES-4 | As a user, I want to re-analyze a resume after making changes | P1 |
| US-RES-5 | As a user, I want to delete a resume I no longer need | P1 |

## Epic: Resume Analysis

| ID | Story | Priority |
|----|-------|----------|
| US-ANA-1 | As a user, I want to see my resume's ATS score (0–100) | P0 |
| US-ANA-2 | As a user, I want to see the breakdown of my score (keywords, formatting, etc.) | P0 |
| US-ANA-3 | As a user, I want to see what's strong about my resume | P0 |
| US-ANA-4 | As a user, I want to see what's weak about my resume with specific advice | P0 |
| US-ANA-5 | As a user, I want AI-powered suggestions to improve specific sections | P1 |

## Epic: JD Matching

| ID | Story | Priority |
|----|-------|----------|
| US-JD-1 | As a user, I want to paste a job description to match against my resume | P0 |
| US-JD-2 | As a user, I want to see my match score as a percentage | P0 |
| US-JD-3 | As a user, I want to see which skills I have that match the JD | P0 |
| US-JD-4 | As a user, I want to see which skills I'm missing for the JD | P0 |
| US-JD-5 | As a user, I want suggestions on how to improve my match score | P1 |
| US-JD-6 | As a user, I want to see my past JD match history | P1 |

## Epic: Interview Preparation

| ID | Story | Priority |
|----|-------|----------|
| US-INT-1 | As a user, I want to start a mock interview based on my resume | P0 |
| US-INT-2 | As a user, I want to start a mock interview based on a specific JD | P1 |
| US-INT-3 | As a user, I want to answer questions one at a time and get feedback | P0 |
| US-INT-4 | As a user, I want to see my score per answer (confidence, accuracy, clarity) | P0 |
| US-INT-5 | As a user, I want a summary when the interview ends | P0 |
| US-INT-6 | As a user, I want to review past interview sessions | P1 |

## Epic: Dashboard & Analytics

| ID | Story | Priority |
|----|-------|----------|
| US-DASH-1 | As a user, I want a dashboard showing my overall progress | P0 |
| US-DASH-2 | As a user, I want to see my resume score history over time | P1 |
